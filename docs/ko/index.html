KnitSnap

뜨개질 진행 사진에 프로젝트 정보를 오버레이로 합성하여 기록하는 iOS 앱

소개

KnitSnap은 뜨개질 프로젝트의 진행 과정을 사진으로 남기고, 사진 위에 프로젝트 이름·바늘·도안·실 등의 정보를 깔끔한 오버레이로 합성해 저장할 수 있는 앱입니다. 모든 데이터는 사용자의 기기에만 저장되며, 외부 서버로 전송되지 않습니다.
