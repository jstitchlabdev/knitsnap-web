사용법

KnitSnap의 주요 기능과 기본 사용 방법을 안내합니다.

1. 시작하기

앱을 처음 실행하면 간단한 온보딩 화면이 나타납니다. 카메라와 사진 접근 권한을 허용하면 모든 기능을 사용할 수 있습니다.

2. 프로젝트 만들기

홈 탭에서 "+" 버튼을 눌러 새 프로젝트를 만들 수 있습니다. 프로젝트에는 다음 정보를 입력할 수 있습니다.

  • 프로젝트 이름
  • 바늘 종류와 호수
  • 도안 이름 / 디자이너
  • 실 정보 (브랜드, 색상 등)
  • 메모

3. 사진 촬영

촬영 탭에서 인라인 카메라로 사진을 찍을 수 있습니다.

  • 줌: 화면을 핀치하거나 하단 배율 버튼으로 조절합니다.
  • 플래시: 상단 아이콘으로 자동/켜짐/꺼짐을 전환합니다.
  • 화면 비율: 4:3, 1:1, 16:9 중 선택할 수 있습니다.
  • 초점/노출: 화면을 탭하여 초점을 맞추고 노출을 조정합니다.

4. 사진 가져오기

이미 찍어둔 사진을 프로젝트에 연결하려면 "사진 가져오기"를 눌러 사진 앱에서 원하는 사진을 선택하세요.

5. 오버레이 편집

사진을 선택하면 오버레이 편집 화면이 열립니다. 프로젝트 정보를 텍스트 오버레이로 사진에 합성할 수 있습니다.

  • 표시할 항목(프로젝트 이름, 바늘, 도안, 실, 타임스탬프)을 선택합니다.
  • 텍스트 색상과 위치를 조정합니다.
  • "저장"을 누르면 오버레이가 합성된 사진이 iOS 사진 앱에 저장됩니다.

6. 풀스크린 뷰어

프로젝트 상세에서 사진을 탭하면 풀스크린 뷰어가 열립니다. 확대/축소, 프로젝트 변경, 사진 기록 삭제 등이 가능합니다.

7. 설정

  • 저장 용량 최적화: 켜면 큰 사진을 2048px로 다운샘플링하여 저장합니다. 용량을 줄일 수 있지만 화질이 소폭 낮아질 수 있습니다.
  • 언어 변경: iOS 설정에서 앱 언어를 한국어/영어로 변경할 수 있습니다.
  • 데이터 초기화: 앱의 모든 프로젝트 데이터를 삭제합니다. (사진 앱에 저장된 사진은 삭제되지 않습니다.)
